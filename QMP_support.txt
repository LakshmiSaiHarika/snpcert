     QMP Integration for sev-verify

     Context

     The sev-verify tool currently launches QEMU with -monitor none, which
     disables the QMP (QEMU Machine Protocol) interface. VM shutdown relies on
     process signals (SIGTERM/SIGKILL). Users have requested the ability to
     manage SEV-SNP guests via JSON attributes using QMP, enabling graceful
     shutdown, VM introspection, and runtime control.

     QMP is QEMU's JSON-RPC-like protocol over Unix sockets that allows:
     - Graceful ACPI shutdown (system_powerdown)
     - Immediate termination (quit)
     - VM introspection (query-status, query-cpus-fast,
       query-memory-size-summary)
     - Pause/resume (stop, cont)

     Implementation Plan

     1. Create QMP Client Module

     New file: sev_verify/qmp_client.py

     Create a synchronous QMP client with:
     - Exception hierarchy: QMPError (base), QMPConnectionError,
       QMPTimeoutError, QMPCommandError
     - Data classes: QMPVersion, QMPStatus, QMPCommandResult
     - QMPClient class with context manager support:
       - connect() - Connect and negotiate capabilities
       - execute(command, arguments) - Generic command execution
       - query_status() - Returns QMPStatus (running, status)
       - query_cpus() - CPU information
       - query_memory() - Memory summary
       - system_powerdown() - Graceful ACPI shutdown
       - quit() - Immediate termination
       - stop() / cont() - Pause/resume
     - Utility functions:
       - generate_qmp_socket_path(profile) - Unique path based on vsock CID
       - wait_for_qmp_socket(path, timeout) - Poll until socket available

     2. Modify VMProfile Dataclass

     File: sev_verify/vm_profile.py

     Add to VMProfile:
     qmp_enabled: bool = True
     qmp_socket_path: str | None = None  # Auto-generated if None
     qmp_timeout: float = 10.0

     Add to VMLaunchResult:
     qmp_socket_path: str | None = None

     def qmp_client(self) -> "QMPClient":
         """Return a QMPClient for this VM."""

     3. Update QEMU Command Building

     File: sev_verify/vm_profile.py, function build_qemu_command()

     Replace -monitor none with QMP socket:
     if profile.qmp_enabled:
         qmp_path = profile.qmp_socket_path or
     f"/tmp/sev-verify-qmp-{profile.vsock_cid}.sock"
         cmd.extend(["-qmp", f"unix:{qmp_path},server,nowait"])
     else:
         cmd.extend(["-monitor", "none"])

     Return tuple (command, qmp_socket_path) instead of just command.

     4. Enhance VM Stop with Graceful Shutdown

     File: sev_verify/vm_profile.py, function stop_vm()

     Add graceful shutdown parameter:
     def stop_vm(launch, *, graceful=True, graceful_timeout=30.0, signal=15,
     timeout=10.0):

     When graceful=True and QMP is available:
     1. Send system_powerdown and wait for clean exit
     2. If timeout, send quit
     3. Fall back to SIGTERM/SIGKILL if QMP fails
     4. Clean up socket file

     5. Add QMP Step Type

     File: sev_verify/models.py

     Update StepKind:
     StepKind = Literal["vm_launch", "vm_stop", "host", "guest", "guest_pull",
     "callable", "qmp"]

     Add validation in BaseStep.__post_init__() for kind == "qmp".

     Add factory methods to Step class:
     def qmp(self, command: str) -> BaseStep
     @classmethod
     def for_qmp(cls, name, type, command, *, expected_result="exit_code:0",
     timeout=10) -> BaseStep

     6. Implement QMP Step Runner

     File: sev_verify/runner.py

     Add run_qmp_step(step, launch) function:
     - Parse command (supports command_name or command_name:{"arg": "value"})
     - Connect to QMP socket, execute command
     - Return StepResult with JSON response in stdout

     7. Integrate in CLI

     File: sev_verify/cli.py

     Add CLI arguments:
     --no-qmp          # Disable QMP (use signal-based shutdown)
     --qmp-timeout     # Timeout for QMP operations (default: 10s)

     Update execute_test() to handle step.kind == "qmp".

     Pass QMP options through effective_vm_profile().

     8. Update vm_launch Integration

     File: sev_verify/vm_profile.py, method VMProfile.vm_launch()

     Capture and return qmp_socket_path in VMLaunchResult.
